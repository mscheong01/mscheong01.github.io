# Minsoo Cheong — Personal Research Website

Static personal website for GitHub Pages.

## Publish

1. Create a public repository named `mscheong01.github.io`.
2. Copy these files to the repository root and push them to the `main` branch.
3. In the repository settings, open **Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.

The site will be available at `https://mscheong01.github.io/` after GitHub finishes the first deployment.

## Add a profile photo

Save the photo as `assets/profile.jpg`, then replace the `.portrait-placeholder` div in `index.html` with the commented `<img>` element immediately above it.

The krotoDC card reads its current star count from GitHub's public repository API. It does not require an API key.
